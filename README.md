# Field Service – rapports d'intervention (version en ligne)

Application web pour les techniciens : base installée, rapports d'intervention selon la trame standard
(13 chapitres, photos, note du jour sur site, signature, PDF) et feuilles d'heures.

**Les données ne sont pas sur GitHub.** Elles sont enregistrées uniquement dans le navigateur de chaque appareil
(IndexedDB). Ce dépôt ne contient que l'interface. Pensez à exporter régulièrement vos données :
*Réglages → Sauvegarde et transfert*.

Fichiers générés automatiquement par `build-github.mjs` depuis l'application principale : ne pas les modifier ici.
